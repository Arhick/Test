# Остаточные — Акт I

Зомби-хоррор с видом сверху, где сюжет строится на моральных решениях игрока.
Фельдшер Илья, сам заражённый, пытается выжить в отрезанном северном городке в первые три дня эпидемии.

**«Остаточные»** — заражённые, которые повторяют действия из прошлой жизни. Пока их не тревожат,
они пассивны. Чем больше игрок убивает, тем они агрессивнее: они учатся у игрока.

## Запуск
Откройте `index.html` в браузере. Сборка и сервер не нужны.

## Что внутри (Акт I, ~25 минут)
- **День 1 «Вызов».** Решение «Одни носилки»: укушенный отец Лизы, лейтенант с пистолетом или оба (с тайной ценой).
- **День 2 «Больница».** Решение «Девочка, которая поёт»: убить, оставить, выпустить или отдать врачу.
- **День 3 «Мост».** Решение: дать взорвать мост, провести беженцев за 2 минуты или сломать детонатор.
- **Ночи.** Распределение еды, ингибиторов и аптечек; события зависят от прошлых решений.
- **Отец Вадим и церковь.** Ночью священник просит ингибиторы для обратившихся прихожан; в День 3 его церковь у моста — светлая с колоколом или тёмная с обратившимся Вадимом.
- **Финал акта.** Сводка решений, кем становится герой, как изменились заражённые, задел на Акт II.

Решения меняют карту (кто стоит у входа в больницу, кто ждёт у моста), людей в убежище и поведение заражённых.

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | фонарь и прицел |
| ЛКМ | выстрел (без пистолета — удар) |
| Пробел / ПКМ | монтировка |
| Shift / C | бег (шумно) / красться |
| F | фонарь вкл/выкл (с фонарём тебя видно издалека) |
| E | действие |
| Q / H / G | ингибитор / аптечка / бросить бутылку (шум-приманка) |
| Tab / Esc | дневник / пауза |

## Структура
- `docs/DESIGN.md` — дизайн-документ и согласованные решения
- `js/state.js` — скрытые оси морали, флаги, чекпоинт дня, сохранение
- `js/maps.js` — карты трёх дней (строятся кодом)
- `js/story.js` — все сцены, выборы и ночные события
- `js/entities.js` — игрок, «остаточные» (ритуал → слух → погоня → возврат), NPC
- `js/world.js`, `js/render.js`, `js/ui.js`, `js/audio.js`, `js/game.js` — движок
